The asbestos data

Counts in 23 grid squares

A study counted asbestos fibers in each of 23 grid squares on a filter. A Poisson model is plausible for the square-to-square variation: counts are nonnegative, and one common rate governs the squares. Here λ is the expected fiber count per square, and the model mean and variance both equal λ.

From model to maximum likelihood estimate

X1, …, Xn ∼ Poisson(λ), independently and identically distributed, λ ≥ 0 P(X = x | λ) = e−λλx/x!, x = 0, 1, …
L(λ) = e−nλλΣxᵢ/∏xᵢ! ℓ(λ) = −nλ + (Σxᵢ) log λ − Σ log(xᵢ!), λ > 0
ℓ′(λ) = Σxᵢ/λ − n = 0 λ̂ = x̄
For these data: L(λ) ∝ e−23λλ573, so λ̂ = 573/23 = 24.913.

Σ
The maximum likelihood estimate depends on the data through their sum. Raising one observation by Δ raises λ̂ by Δ/n. Redistributing counts without changing the sum leaves λ̂ unchanged—even though the absolute height of the likelihood can change through ∏xᵢ!. The likelihood is a function of λ after the observations are fixed; it is not a probability distribution for λ.
