Confidence intervals

Follow one interval, then many, to see what repeated-sample coverage means for an unknown Normal mean.

The problem

A Normal source has unknown mean μ and unknown standard deviation σ. We observe n = 50 independent values and want an interval that expresses uncertainty about μ.

X1, …, Xn ∼ N(μ, σ2),  n = 50,  μ and σ unknown

A 1.96-based confidence interval

For each sample, use its average and sample standard deviation to construct an approximate 95% confidence interval for μ.

X̄ ± 1.96 · S/√n

What is random?

S uses the n − 1 denominator. The true μ stays fixed, while X̄, S, and both interval endpoints change from sample to sample.
